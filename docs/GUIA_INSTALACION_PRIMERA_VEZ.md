# Guía de Instalación — Primera vez

## CaracT Móvil

> Siga estos pasos en orden. Solo necesita hacerlo una vez.

---

## PASO 1 — Abrir el enlace de descarga

Abra el enlace que le enviaron desde el **navegador de su celular** (Chrome, Samsung Internet, etc.).

```
┌─────────────────────────────┐
│  Chrome / Navegador         │
│                             │
│  github.com/Anvid31/...     │
│                             │
│  [ Descargar ]  ← toque    │
└─────────────────────────────┘
```

El archivo APK se descargará automáticamente (puede tardar 1-2 minutos según la conexión).

---

## PASO 2 — Permitir la instalación desde el navegador

Al terminar la descarga, Android puede mostrar este aviso:

```
┌─────────────────────────────┐
│  Por seguridad, tu teléfono │
│  no puede instalar archivos │
│  desconocidos de Chrome.    │
│                             │
│  [ Configuración ]          │
└─────────────────────────────┘
```

**Si aparece este aviso:**

**1.** Toque **"Configuración"** (o "Ajustes") en ese mismo aviso

**2.** Active el interruptor que aparece

```
Instalar apps desconocidas

  Permitir a Chrome instalar
  otras aplicaciones

  [  ●  ]   ← debe quedar así (azul)
```

**3.** Toque **← Atrás** para volver a la descarga

---

**Si el aviso no apareció**, vaya manualmente:

```
⚙️ Ajustes
└── Aplicaciones
    └── Chrome (o su navegador)
        └── Instalar apps desconocidas
            └── Activar
```

> ⚠️ Este permiso solo se usa para instalar CaracT Móvil.
> Puede desactivarlo después si lo desea.

---

## PASO 3 — Instalar la aplicación

Una vez descargado, el instalador aparece solo:

```
┌─────────────────────────────┐
│  ¿Desea instalar esta       │
│  aplicación?                │
│                             │
│  CaracT Móvil               │
│                             │
│  [ Cancelar ] [ Instalar ]  │
└─────────────────────────────┘
```

Toque **"Instalar"** y espere unos segundos.

---


## PASO 4 — Abrir la aplicación

```
┌─────────────────────────────┐
│  Aplicación instalada.      │
│                             │
│  [ Listo ]  [ Abrir ]       │  ← toque Abrir
└─────────────────────────────┘
```

**¡Listo!** La próxima vez que haya una actualización, la aplicación le avisará sola y no necesitará repetir estos pasos.

---

## Si el instalador no abre después de la descarga

Vaya a las **Notificaciones** de su celular (deslice hacia abajo desde arriba) y busque la notificación de descarga completada:

```
┌─────────────────────────────┐
│ ↓  Descarga completa        │
│    app-release.apk    ←  toque aquí
└─────────────────────────────┘
```

También puede ir a la carpeta **Descargas** de su celular y tocar el archivo `app-release.apk`.

---

## Preguntas frecuentes

**¿Es seguro instalar desde este enlace?**
Sí. El enlace lo envió el administrador de la aplicación y el archivo está firmado oficialmente.

**¿Por qué Android pide permiso para instalar?**
Por seguridad, Android solo permite instalar desde la tienda oficial (Play Store) por defecto. Como esta app es de uso interno y no está en Play Store, hay que dar este permiso una sola vez.

**¿Tengo que hacer esto cada vez que actualice?**
No. Las actualizaciones futuras llegan automáticamente desde dentro de la app. Estos pasos son solo para la primera instalación.
