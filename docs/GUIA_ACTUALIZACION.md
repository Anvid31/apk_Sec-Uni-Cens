# Guía de Actualización — CaracT Móvil

> Esta guía es para los docentes que usan la aplicación.  
> Solo necesitan seguir los pasos en orden. No se necesita saber de tecnología.

---

## ¿Para qué sirve una actualización?

Las actualizaciones mejoran la aplicación: corrigen errores, agregan funciones nuevas o cambian cosas de la pantalla. La app avisa sola cuando hay una disponible.

---

## PASO 1 — Abrir la aplicación normalmente

Toque el ícono de **CaracT Móvil** como siempre.

```
┌─────────────────────────┐
│                         │
│   [ícono CaracT Móvil]  │
│                         │
└─────────────────────────┘
         ↑
    Toque aquí
```

> Si hay una actualización disponible, un aviso aparecerá solo en pantalla
> en los primeros segundos. No tiene que buscar nada.

---

## PASO 2 — Leer el aviso de actualización

Aparecerá una ventana como esta:

```
╔═══════════════════════════════╗
║   ↑  Actualización            ║
║      disponible               ║
║      v1.0.3 — Interfaz limpia ║
╠═══════════════════════════════╣
║                               ║
║  Actual  →  Nueva             ║
║  v1.0.1     v1.0.3            ║
║                               ║
║  Novedades:                   ║
║  - Se eliminó el botón de     ║
║    Exportar Shapefile          ║
║  - Mejoras de estabilidad     ║
║                               ║
╠═══════════════════════════════╣
║  [ Después ]  [ Actualizar ]  ║
╚═══════════════════════════════╝
```

| Botón | ¿Qué hace? |
|-------|-----------|
| **Actualizar** | Descarga e instala la nueva versión |
| **Después** | Cierra el aviso. Volverá a aparecer la próxima vez que abra la app |

**Toque "Actualizar"** para continuar.

## Si aparece un error — "Instalar apps desconocidas"

En algunos celulares, la primera vez que se actualiza aparece este mensaje de error:

```
╔═══════════════════════════════╗
║   ✕  Error al abrir           ║
║      instalador               ║
╠═══════════════════════════════╣
║                               ║
║  Si el error persiste, ve a:  ║
║  Ajustes → Aplicaciones →     ║
║  CaracT Móvil →               ║
║  Instalar apps desconocidas   ║
║  → Permitir                   ║
║                               ║
╚═══════════════════════════════╝
```

**Esto solo pasa una vez.** Siga estos pasos para resolverlo:

---

### Cómo activar "Instalar apps desconocidas"

#### En Android 8 o más nuevo (la mayoría de celulares):

**1.** Abra **Ajustes** (el ícono de engranaje ⚙️ del celular)

**2.** Busque y toque **Aplicaciones** o **Gestión de aplicaciones**

```
⚙️ Ajustes
├── Conexiones
├── Sonidos
├── Notificaciones
├── Aplicaciones          ← toque aquí
└── Pantalla
```

**3.** Busque **CaracT Móvil** en la lista de apps

```
Aplicaciones instaladas
├── Calculadora
├── Cámara
├── CaracT Móvil          ← toque aquí
└── Contactos
```

**4.** Busque la opción **Instalar apps desconocidas** o **Permiso especial**

```
CaracT Móvil
├── Permisos
├── Almacenamiento
├── Instalar apps desconocidas    ← toque aquí
└── Notificaciones
```

**5.** Active el interruptor

```
Instalar apps desconocidas

  Permitir a esta aplicación
  instalar otras aplicaciones

  [  ●  ]   ← debe quedar así (azul/activado)
```

**6.** Regrese a la aplicación CaracT Móvil y toque **Reintentar**

```
╔═══════════════════════════════╗
║   ✕  Error al abrir           ║
║      instalador               ║
╠═══════════════════════════════╣
║  ...                          ║
╠═══════════════════════════════╣
║  [ Cerrar ]  [ Reintentar ]   ║  ← toque Reintentar
╚═══════════════════════════════╝
```

## Preguntas frecuentes

**¿Pierdo la información que había guardado si actualizo?**  
No. Toda la información de encuestas guardadas se mantiene.

**¿Qué pasa si cierro la app mientras descarga?**  
La descarga se cancela. La próxima vez que abra la app, el aviso aparecerá de nuevo y puede volver a intentarlo.

**¿Tengo que conectarme a WiFi para actualizar?**  
No es obligatorio, pero se recomienda. Una actualización pesa entre 60 y 70 MB. Con datos móviles puede tardar más o consumir su plan.

**¿Cada cuánto sale una actualización?**  
No hay una frecuencia fija. Solo aparece cuando los administradores publican una versión nueva.

**¿Puedo ignorar la actualización?**  
Sí, tocando "Después". Pero se recomienda actualizar para tener la versión más estable.
